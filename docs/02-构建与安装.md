# 02 · 构建与安装

## 一、环境

| 组件 | 版本 | 说明 |
|---|---|---|
| Theos | 最新主线 | `$THEOS` |
| iOS SDK | `iPhoneOS16.5.sdk` | 私有框架 `.tbd` 齐全（CoverSheetKit / SpringBoardFoundation / Preferences） |
| clang | 19.0.0（L1ghtmann Linux 工具链） | 能为 arm64e 产出 `ptr_format=12` 的 chained fixups |
| ld64 | 956 | 同上 |
| ldid | Procursus 版 | 重签 |
| WSL | Ubuntu 22.04 | 推荐构建环境 |

本仓库的 `build.sh` 默认路径：

```
$HOME/theos
$HOME/tc19/linux/iphone/bin/{clang,clang++,ldid}
```

改成自己的即可。

## 二、编译

```bash
# 在 WSL 里执行
bash /path/to/LSTimeSeconds/build.sh
```

脚本流程：

1. 复制源码到 `$HOME/lsts_github_build`，**把所有文本文件 CRLF 转 LF**（Windows 侧编辑过也要转，
   `ldid`/`ld64` 对 CRLF 敏感）；
2. `make clean` → `make package FINALPACKAGE=1`，并用 `TARGET_CC/CXX/LD/CODESIGN`
   指向 clang 19 工具链；
3. `dpkg-deb -R` 解包；
4. 对 **`LSTimeSeconds.dylib`** 与 **`LSTSPrefs`（设置面板可执行文件）** 分别做 isa 补认证；
5. `ldid -S` 分别重签；
6. 修权限（两个二进制 755，plist 644）；
7. `dpkg-deb -b -Zxz` 重新打包。

成功后产物：`com.sini921.lstimeseconds_0.0.8-1_iphoneos-arm64e.deb`。

## 三、为什么链接完还要改二进制

### 3.1 现象

补丁前在设备上加载 dylib，SpringBoard 直接崩，进安全模式，崩溃栈在
`objc_msgSend` 且指针是未认证的（典型 `SIGBUS`）。

### 3.2 机理

- SpringBoard / Preferences 都是 **arm64e** 进程，指针带 PAC。
- clang 19（Linux 工具链）给 arm64e 编 `CFSTR(@"...")` 常量时，`__cfstring` 结构的
  `isa` 字段用的是 **普通 `ARM64_RELOC_UNSIGNED` 重定位**，不是
  `ARM64_RELOC_AUTHENTICATED_POINTER`。
- ld64 据此在 `LC_DYLD_CHAINED_FIXUPS` 里把 isa 写成 **plain bind**（无 PAC）。
- 运行期 `objc_msgSend` 收到常量字符串做接收者时会验证 isa，未签名 → 认证失败 → `SIGBUS`。

### 3.3 对照

Xcode 编的原版（三个 dylib 交叉验证一致）里 isa 全部是 **auth bind**：

```
diversity = 0x6AE1     // objc4 的 ISA 签名常量
addrDiv   = 1
key       = 2          // IA key
```

### 3.4 补丁规则

`build.sh` 内嵌 Python，只处理 `cpusubtype == 0x80000002`（arm64e）切片的
`__DATA_CONST,__cfstring`，按 32 字节结构步长定位每个 isa 槽：

```
auth bind24 位布局：
  [0:24)   ordinal（保留原值）
  [32:48)  diversity = 0x6AE1
  [48]     addrDiv = 1
  [49:51)  key = 2
  [51:62)  next（保留原值）
  [62]     bind = 1
  [63]     auth = 1
```

`arm64` 切片（plain pointer，无认证概念）保持不动。补完必须 `ldid -S` 重算 CodeDirectory。

> 常见坑：只补 dylib 忘了补设置面板。Preferences 同样是 arm64e 进程，
> 面板二进制不补会一进设置就崩。

## 四、安装

1. 用 Sileo / Zebra / Filza 安装 `release` 里的 deb；
2. **不要**过 RootHide 转换器（本包已是原生 `iphoneos-arm64e`，转换器会重写二进制并破坏 PAC）；
3. `Respring` 一次；
4. 点亮锁屏验证秒数每秒递增；
5. 打开「设置 → LSTimeSeconds」调整字号与垂直位置。

## 五、验证清单

构建完可以按这套断言自查（与 `build.sh` 一致）：

| 检查项 | 期望 |
|---|---|
| FAT 切片 | `arm64` + `arm64e` 各一 |
| 文件类型 | dylib = `MH_DYLIB`；面板可执行文件通常也为 `MH_DYLIB`（与原作者产物一致） |
| 依赖 | dylib 含 `@loader_path/.jbroot/usr/lib/libsubstrate.dylib`（不是 `@rpath/CydiaSubstrate`） |
| chained fixups | arm64e 切片 `pointer_format == 12` |
| `__cfstring` isa | 全部 `auth=1, div=0x6AE1, addrDiv=1, key=2`，plain 计数为 0 |
| 权限 | `LSTimeSeconds.dylib`、`LSTSPrefs` 均 755 |
| 面板 | `Info.plist` 的 `NSPrincipalClass = LSTRootListController`，包内有该符号 |
| 包信息 | `Architecture: iphoneos-arm64e`，`Depends: mobilesubstrate, preferenceloader` |

## 六、排障

设备侧日志：`/var/mobile/Library/LSTimeSeconds.log`（写不进去时退到 `/tmp/LSTimeSeconds.log`）。

正常启动应看到：

```
>>> LSTimeSeconds ctor initialized in process SpringBoard (PID xxxx) <<<
loadPrefs: enabled=1, scale=0.88, yOffset=0.0, aodOpt=1
CSProminentDisplayViewController viewDidLoad
registerActiveTimeView: count=1
CSProminentTimeView didMoveToWindow: ON SCREEN
```

- 只有 `ctor` 没有 `didMoveToWindow` → 视图没抓到（类名/Hook 目标变了）；
- 有 `didMoveToWindow` 但时间不动 → 看 `_date` 是否推进、`*_timeFormatter` 是否拿到；
- 完全没日志 → dylib 没被加载（检查权限 755、过滤器、是否被转换器改写过）。
